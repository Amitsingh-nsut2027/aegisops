# Public portfolio deployment — 2026-10-19

Live URL: https://d2mmk7avpz0dbe.cloudfront.net

## What is hosted

The two approved interactive frontend screens use a static fixture generated by the real local fake-provider workflow: 14 simulated CPU incidents and 33 independent saved investigation reports. The persistent portfolio banner identifies scripted evidence and no model calls. The Python/PostgreSQL backend remains local. There is no public write API, live AWS monitoring, autonomous remediation, or paid model inference in this release.

## Hosting and release

CloudFormation stack: aegisops-portfolio, us-east-1. Distribution: E19WZE6S33AVNF. The private bucket is account-scoped; its exact outputs stay in the ignored local deployment record. All S3 public access blocks are enabled; the bucket grants read access only to this CloudFront distribution, with signed origin requests and encrypted storage. CloudFront redirects HTTP to HTTPS.

Deployment used the scoped aegis-dev identity. AWS Support verified CloudFront access while preserving the Free plan and credits. The prior failed stack had no remaining resources and was removed before retry. The final stack reached CREATE_COMPLETE; all 16 artifact files were uploaded and cache invalidation completed. The deployer never uploaded .env, credentials, the local database, or the backend.
